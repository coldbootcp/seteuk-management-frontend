# v0.2 전체 제품 프로토타입 구현 매핑

## 목적

사용자가 제공한 `seteuk-ai-harness-v0.2.md`를 화면 설명이 아니라 실제 저장 상태와 API가 있는 종단 간 제품으로 옮긴다. 학생 간 개인화 성능 평가는 후속 단계이며, 현재 목표는 한 명의 신규 학생이 모든 주요 기능을 연속해서 사용할 수 있게 하는 것이다.

## Planning 루프

| v0.2 단계 | 구현 |
|---|---|
| INTERVIEW_COLLECT | 신규 학생 온보딩 폼 |
| SEARCH_NARRATIVE_TEMPLATE | 반도체 서사 템플릿 v1 선택 |
| PERSONALIZE_TEMPLATE | 관심 키워드와 현재 학년·학기로 활성 노드 조정 |
| GENERATE_ROADMAP_NODES | 1학년 1학기부터 3학년 2학기까지 6개 노드 생성 |
| REVIEW_ROADMAP | 잠정 DNA, 제안임을 표시하고 제목·목표 편집 제공 |
| USER_REVIEW | 미리보기 화면에서 학생이 직접 수정 |
| SAVE_ROADMAP_V1 | D1에 프로필, 로드맵, 노드 저장 |

로드맵 전체 재생성은 이전 버전을 `superseded`로 남기고 새 활성 버전을 만든다.

## Reconciliation 루프

활동을 저장하면 교과, 개념, 반도체 도메인 신호, 활성 노드의 목표를 비교한다.

- `MATCH`: 현재 노드 완료, 다음 노드 활성화
- `PARTIAL_MATCH`: 현재 노드 부분 충족으로 기록하고 다음 단계로 이동
- `DIVERGE`: 로드맵 밖 활동으로 보존하고 진로 변화 가능성을 열어둠
- `MISS`: 학기 체크포인트까지 완료 활동이 없을 때 학생이 이월 또는 건너뛰기를 결정
- `UNCLASSIFIABLE`: 활성 노드가 없을 때 독립 활동으로 저장

판정 결과에는 이유, 조치, 신뢰도를 남기며 활동 타임라인과 함께 조회한다. `MISS`는 신규 활동의 분류가 아니라 시간 기반 체크포인트 이벤트로 별도 처리한다.

## 기억 갱신

- 학생 직접 입력 정보가 AI 추론보다 우선한다.
- 프로필 수정 시 DNA를 즉시 다시 계산한다.
- 진로 변경 시 로드맵 새 버전을 선택적으로 생성한다.
- 활동 추가 시 Evidence 후보와 정합 이력이 누적된다.
- 기존 추천 및 로드맵 실행 기록은 덮어쓰지 않는다.

## 현재 경계

실제 OCR, 교육과정 검색, 외부 논문 검색, 실제 LLM 호출은 아직 연결하지 않았다. UI와 API는 이 기능들이 들어갈 계약 경계를 유지하며 현재는 결정론적 mock으로 종단 간 흐름을 검증한다.
