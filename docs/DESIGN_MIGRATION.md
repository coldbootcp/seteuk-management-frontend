# 디자인 마이그레이션 — preview-3200 → 실서비스 프론트엔드

목업(`preview-3200/index.html`, 3200 포트)의 디자인을 실제 서비스(3100 포트)로 옮기는
작업의 계획과 판단 근거를 남긴다. **기능의 정본은 3100이고, 디자인의 정본은 3200이다.**

## 0. 출발점에서 확인한 사실

- 목업은 React 18 + Tailwind(CDN) + Pretendard로 쓰인 **단일 파일 정적 목업**이다.
  데이터는 전부 하드코딩이고 백엔드 호출이 없다.
- 목업 사이드바 주석에 `(Matching 3100 port)`가 적혀 있다 — 목업은 우리 화면을
  기준으로 다듬어 만든 것이라, 전면 재작성이 아니라 **정제**에 가깝다.
- 두 쪽의 색 팔레트가 이미 같다: `#3182F6`(Toss action blue), 텍스트 `#191F28`,
  표면 `#F2F4F6`, 경계 `#E5E8EB`.
- 3100의 `globals.css`는 `--font-body`의 첫 후보로 이미 `Pretendard`를 적어 두고도
  폰트를 내려받지 않아 시스템 폰트로 대체되고 있었다.

## 2. 전략 — 왜 이 방법인가

세 가지 선택지를 두고 판단했다.

1. **CSS만 갈아끼우기** — 마크업을 그대로 두고 `globals.css`만 목업처럼 고친다.
   위험은 가장 낮지만, 목업에만 있는 구조(상단 검색바, 카드 안 배지, 진행 스트립)는
   재현할 수 없다.
2. **Tailwind로 전면 재작성** — 충실도는 가장 높지만 모든 화면의 JSX를 건드려야 해서
   핸들러가 끊길 위험이 크고, 같은 파일을 동시에 편집 중인 작업과 충돌한다.
3. **혼합(채택)** — 기반을 먼저 깔고, 화면을 하나씩 옮기며 매번 동작을 확인한다.

**Tailwind 유틸리티를 preflight(리셋) 없이 켰다.** 목업 마크업을 번역 없이 옮기기
위해서다. 리셋을 켜지 않은 이유는 `globals.css`가 이미 자체 리셋을 갖고 있어서
그 위에 Tailwind 리셋을 얹으면 기존 6,600줄이 기대하는 기본값이 조용히 어긋나기
때문이다. 클래스 이름 충돌은 없다(우리 CSS의 클래스는 전부 `.dna-card` 같은
의미 이름이고, 유틸리티와 겹치는 이름은 `.btn` 하나인데 Tailwind는 `.btn`을
만들지 않는다).

## 3. 단계

- [x] **Phase 1 — 기반**: Pretendard 로드, Tailwind 유틸리티(리셋 제외) 활성화,
      목업의 테마 토큰(brand 50~900, surface, shadow 4종)을 `@theme`으로 이식.
- [ ] **Phase 2 — 셸**: 사이드바(브랜드/학생 카드/네비/하단)와 상단바(breadcrumb,
      검색, 배지, 알림·설정)를 목업 구조로. 탭 순서도 목업에 맞춘다.
- [ ] **Phase 3 — 화면 이식** (기능 유지, 하나씩 확인):
      이번 학기 → 활동 & 세특 → 3개년 로드맵 → 대시보드(신규) → 수시 포트폴리오
      → AI 컨설턴트 → 프로필 설정 → 상담 게이트 → 로그인
- [ ] **Phase 4 — 성적/시간표 톤 맞춤**: 이 두 화면은 최근에 따로 만들어진 것이라
      구조는 두고 색·간격·그림자만 맞춘다(건드리는 범위를 최소화).
- [ ] **Phase 5 — 비로그인 랜딩**(선택): 아래 4절의 확인이 끝난 뒤에만.

## 4. 목업에 있지만 백엔드가 받쳐주지 못하는 것

옮기기 전에 판단이 필요한 항목들이다. 화면만 만들면 눌러도 아무 일이 없거나,
사실이 아닌 것을 사실처럼 보여주게 된다.

| 목업 요소 | 상태 | 처리 |
|---|---|---|
| 상단 전역 검색(⌘K) | 검색 엔드포인트 없음 | 화면에 두되 **클라이언트 필터**로 축소하거나 보류 |
| 알림 벨 | 알림 도메인 자체가 없음 | 장식으로 두지 않고 **제외** |
| Pro / VIP 요금제·결제 | `CLAUDE.md`에 "결제·구독은 범위 제외" 명시 | 배지는 **장식 표기**로만, 결제 흐름 없음 |
| "재학생 / 인증" 배지 | 학교 인증 개념 없음 | 정적 문구로 표기 |
| 전교 석차 백분위·전국 수능 대비 | 백엔드에 없는 통계 | **계산 가능한 값만** 표시(평균 등급, 이수 단위) |
| 활동 카드 "일치도 98%" | `reconciliation_logs.confidence`로 대체 가능 | 실제 값 사용 |
| 랜딩의 누적 수치·합격률·후기 | **실제 데이터 아님** (14,800+ / 92.4% / ★4.98 / 합격 사례) | 사실이 아닌 수치를 실서비스에 그대로 쓸 수 없다 — 소유자 확인 필요 |

## 5. 원칙

- **기능이 먼저다.** 디자인을 옮기다 핸들러·상태·API 호출이 끊기면 그 이식은 실패다.
  화면 하나를 옮길 때마다 실제로 눌러 보고 넘어간다.
- **없는 데이터를 지어내지 않는다.** 목업의 하드코딩 수치는 실제 값으로 바꾸거나,
  값이 없으면 그 자리를 비운다.
- **동시에 편집 중인 파일을 존중한다.** 성적·시간표 화면은 다른 작업에서 만들어지고
  있으므로 구조를 갈아엎지 않고 톤만 맞춘다.
